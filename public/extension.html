Pasang BlackMamer untuk Chrome desktop.

Pasang dari file ZIP

Unduh paket gratis, lalu tambahkan folder ekstensi ke Chrome.

Unduh BlackMamer v4.0.1 (.zip)
  1. Ekstrak ZIP ke folder tetap di komputer.
  2. Buka tab baru dan ketik chrome://extensions.
  3. Aktifkan Developer mode, klik Load unpacked, lalu pilih folder BlackMamer-v4 yang berisi manifest.json.
  4. Buka Details pada BlackMamer dan aktifkan Allow user scripts jika tersedia.
  5. Muat ulang halaman ini atau buka kembali link pembelian.

Sudah memakai v4? Untuk memperbarui, timpa file di folder ekstensi yang sama lalu klik Reload di chrome://extensions. Pertahankan folder dan instalasinya agar data lisensi tetap tersimpan.
