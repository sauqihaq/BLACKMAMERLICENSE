Manual Payment Workflow

1. Pembeli pilih tool dan klik kontak.
2. Kamu verifikasi pembayaran lewat Discord/WA.
3. Buka Produk & Akses, pilih produk dan username.
4. Kirim link install privat tanpa key manual.

Catatan: key tidak otomatis terbit ketika pengguna hanya menghubungi admin. Validasi perangkat tetap berjalan di Vercel.

Informasi penting

Nama pengguna yang ditampilkan berasal dari isian ketika aktivasi, bukan identitas yang diverifikasi oleh Tripo3D. Device ID bukan serial hardware Windows dan masih dapat disalin atau dipalsukan.

Jika lisensi di-revoke, validasi berikutnya gagal. Userscript yang berada di perangkat pelanggan tetap dapat dimodifikasi; jangan anggap pemeriksaan di sisi browser mustahil dilewati.
