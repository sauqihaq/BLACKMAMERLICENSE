Cara pembelian

Memuat katalog…

Harga ditentukan oleh admin. Lisensi diterbitkan setelah pembayaran dikonfirmasi.

Cara pembelian.

  1. Pilih tool

    Buka detail produk dan cek harga hariannya.

  2. Pesan lisensi

    Klik Pesan untuk memilih durasi lewat WhatsApp. Opsi Discord tersedia di detail produk bila diaktifkan admin.

  3. Terima link pribadi

    Setelah pembayaran dikonfirmasi, admin mengirim link pemasangan dengan batas waktu.

  4. Pasang di browser

    Pasang ekstensi BlackMamer, buka link pribadi, lalu konfirmasi pemasangan.

Bantuan.

Bagaimana pembayaran dikonfirmasi?

Admin mengirim instruksi pembayaran melalui kontak resmi. Tunggu konfirmasi sebelum melakukan transfer.

Apakah satu lisensi berlaku untuk semua tools?

Setiap lisensi berlaku untuk satu produk. Pilih lisensi terpisah jika kamu membutuhkan tool lainnya.

Model apa yang boleh digunakan?

Gunakan model milikmu, model dengan izin pemilik, atau aset yang tersedia untuk diunduh secara resmi. Lisensi BlackMamer tidak memberikan hak atas karya pihak ketiga.
